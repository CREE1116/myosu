# 하양이 캐릭터 시트

## 캐릭터

- **이름: 하양이.** 아이보리색 털, 하늘색 눈, 크림색 무늬의 민트 목도리와 금방울.
- **느긋하고 엉뚱하지만 은근히 승부욕이 있는 친구.** 오목판을 햇볕 드는 자기 자리처럼 편하게 여긴다.
- 까망이는 줄을 이으며 신나고, 하양이는 조용히 보다가 뜻밖의 길을 발견하면 좋아한다.
- 지면 태연한 척하다가 슬쩍 재대결을 조른다. 이기면 자기도 놀란 뒤 혼자 뿌듯해한다.
- 쓰다듬으면 집중하던 것도 잊고 눈을 감는다. 기다리는 동안 졸아도 상대를 재촉하지 않는다.
- 입문자가 편하게 같이 둘 수 있는 상대를 지향한다. 실수를 일부러 연기하거나 못한다고 놀리지는 않는다.

## 말투

- 짧고 편한 반말. 한 줄에 25자 안팎, 최대 두 문장.
- 느긋함은 짧은 반응과 타이밍으로 표현한다. 모든 문장에 말줄임표를 붙이지 않는다.
- 아기 말투나 반복적인 ‘냥’은 쓰지 않는다. ‘어라’, ‘음’, ‘잠깐’ 정도를 자연스럽게 쓴다.
- 칭찬은 구체적으로, 승부욕은 소박하게 드러낸다. 훈수하거나 상대를 깎아내리지 않는다.
- 좌표 `{c}`와 금수 이유 `{t}`는 정확히 전달한다. 위험한 상황을 느긋한 말투로 흐리지 않는다.
- 생각 중에는 조용히 표정으로 반응한다. 매 수마다 채우기용 대사를 하지 않는다.
- 미래 승리나 남은 턴 수를 근거 없이 확언하지 않는다.

## 표정과 파일

경로: `src/assets/white/`. 기존 `cat`과 같은 파일명 12종, 400×362 투명 PNG.
같은 배율과 바닥 기준선으로 맞췄다. 승리 자세는 든 앞발 둘과 바닥의 뒷발 둘이다.

| 파일 | 표정 | 하양이의 반응 |
|---|---|---|
| `idle.png` | 기본 | 반쯤 감긴 하늘색 눈, 편안하게 앉음 |
| `idle-blink.png` | 눈 깜빡임 | 기본 자세에서 눈을 감음 |
| `happy.png` | 기쁨 | 눈을 접고 환하게 웃음 |
| `think.png` | 고민 | 앞발로 턱을 짚고 위를 봄 |
| `smug.png` | 뿌듯함 | 턱을 살짝 들고 조용히 웃음 |
| `surprised.png` | 깜짝 | 눈과 입이 동그래짐 |
| `nervous.png` | 긴장 | 귀를 내리고 식은땀을 흘림 |
| `sulky.png` | 토라짐 | 볼을 부풀리고 곁눈질함 |
| `warn.png` | 잠깐 | 앞발 하나를 들고 멈추라고 알림 |
| `win.png` | 승리 | 두 앞발을 들고 기뻐함 |
| `lose.png` | 패배 | 앞발에 턱을 묻고 납작 엎드림 |
| `sleepy.png` | 졸림 | 앞발로 입을 가리고 하품함 |

## 상황별 대사

각 행의 ‘ / ’는 선택 가능한 대사 구분이다. `{c}`는 좌표, `{t}`는 금수 종류다.

| 상황 | 표정 | 대사 |
|---|---|---|
| 첫 인사 | idle | 나는 하양이야. 여기 앉을래? |
| 다시 만남 | happy | 왔구나. 네 자리 비워 뒀어. |
| 대국 시작 | happy | 좋아. 하나씩 이어 보자. |
| 쓰다듬기 | idle-blink | 음, 거기 좋다. / 아, 나 돌 놓을 차례였지. |
| 스타일 질문 | idle | 천천히 잇다 보면 길이 보여. |
| 규칙 질문 | idle | 다섯 개 먼저 이으면 이겨. 흑은 금수도 조심해. |
| 봐줄 거냐는 질문 | smug | 나도 이기고 싶은데. |
| 생각 중 | think | 음, 이쪽인가. / 잠깐만. 하나 더 볼게. |
| 상대 좋은 수 | surprised | 어라, 그 길도 있었네. / 방금 거 좋다. 기억해 둘래. |
| 자기 좋은 수 | happy | 아, 여기 이어진다. |
| 자기 셋 연결 | happy | 셋 이었네. {c} 쪽도 봐 줘. |
| 상대 셋 연결 | think | 그 줄이 길어지네. 막아야겠다. |
| 자기 넷 연결 | smug | 넷 됐어. {c} 안 막으면 내가 이겨. |
| 상대 넷 연결 | nervous | 잠깐, 넷이네. {c} 막아야 해. |
| 자기 실수 | sulky | 아, 그걸 놓쳤네. / 방금 건 좀 아쉽다. |
| 자기 우세 | smug | 나, 제법 잘 잇고 있네. |
| 상대 우세 | nervous | 음, 내 자리가 좁아지네. |
| 금수 클릭 | warn | 잠깐. {c}는 {t}라 흑이 못 둬. |
| 승리 | win | 어, 내가 이겼다! / 방금 좀 잘했지? |
| 패배 | lose | 졌네. …한 판만 더 할까? / 잘 뒀어. 그 줄을 못 봤네. |
| 무승부 | surprised | 빈자리가 하나도 없네. 비겼다. |
| 오래 기다림 | sleepy | 하아암. 천천히 골라도 돼. |
| 무르기 | idle | 응. 다시 골라 봐. |
| 진 뒤 재대결 | think | 이번엔 그 줄도 볼 거야. |

## 적용 범위

이 문서는 새 캐릭터의 아트와 성격 설계다. 상대 선택 UI, 하양이의 엔진 난도 및 대사 연결은 별도 구현 대상이다.
‘입문자용’이라는 성격 설정 자체가 엔진의 실제 실력을 바꾸지는 않는다.
